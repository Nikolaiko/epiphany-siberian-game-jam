# Epiphany

Пиксельная приключенческая игра о студенте, который готовит доклад о Ледовом побоище. Он отправляется по городу подтвердить знакомые тезисы, но разговоры, исторические источники и мини-игры заставляют его пересмотреть свои убеждения.

Epiphany — «прозрение». Главная идея игры: настоящая история интереснее привычного мифа, а проверять источники полезнее, чем искать подтверждение собственной правоты.

Проект разрабатывается на **Godot 4.7** в рамках серии стримов. Сейчас это прототип: отдельные сцены уже работают, полное прохождение ещё в разработке.

## Как устроена игра

По сценарию игрок начинает в кофейне, исследует город и посещает музей, архив и кинотеатр. В каждой локации он проверяет один из тезисов будущего доклада:

- В музее сравнивает снаряжение участников битвы.
- В архиве ищет слова в летописи.
- В кинотеатре отличает исторические свидетельства от образов из фильма.
- В сквере встречается с аспирантом Глебом и разбирается, кто за кого воевал.

Открытия попадают в блокнот: карточки переворачиваются с мифа на факт с указанием источника. В финале студент собирает доклад из того, что успел узнать. Запланированы три концовки.

Полный сюжет, реплики и исторические источники — в [сценарии](docs/story.md).

## Текущее состояние

В рабочей версии доступны:

- Прототип вступления с фонами, портретом и переключением страниц диалога.
- Переход из вступления в город.
- Городская карта с движением студента, препятствиями и следящей камерой.
- Отдельные прототипы поиска слов и сравнения снаряжения.
- Материалы стайл-теста: фоны, портреты, спрайт студента и городская графика.

Входы в здания пока не запускают полноценные локации. Блокнот, общий игровой прогресс, финал и публикация web-версии входят в план разработки. У студента есть анимации ходьбы вверх и вниз; при движении вбок пока используются неподвижные позы.

## Запуск

Понадобится **Godot 4.7 Standard**; .NET не требуется.

1. Склонируй репозиторий или скачай архив нужной ветки:

   ```bash
   git clone --branch dev https://github.com/Nikolaiko/epiphany-siberian-game-jam.git
   cd epiphany-siberian-game-jam
   ```

2. В менеджере проектов Godot нажми **Import / Импортировать**, выбери `project.godot` и открой проект.
3. Дождись импорта ресурсов.
4. Открой `scenes/main_scene/main_scene.tscn` и нажми **F6 — запуск текущей сцены**. Начнётся вступление; после последней страницы кнопка «Начнём!» откроет город.

Для просмотра только города открой `scenes/walkable_city/City.tscn` и нажми **F6**.

**Пока используй F6:** в настройках проекта основной сценой ещё назначена мини-игра со словами, поэтому F5 запускает её. Исправление стартовой сцены запланировано в серии 1.

Для актуального прототипа используй ветку `dev`. Содержимое `main` может отставать до завершения очередной серии.

### Управление

| Действие | Управление |
|---|---|
| Передвижение по городу | Стрелки |
| Следующая страница вступления | Кнопка «Далее» |
| Переход из вступления в город | Кнопка «Начнём!» |

### Отдельные прототипы

Открой нужную сцену в редакторе и нажми F6:

| Прототип | Сцена |
|---|---|
| Поиск слов | `scenes/letters_minigame/letter_mini_game.tscn` |
| Сравнение снаряжения | `scenes/comparison_minigame/compare_minigame.tscn` |

## Графика

Ориентиры стайл-гайда: палитра **Resurrect 64** от Kerrie Lake, базовое разрешение 640×360, тайлы города 16×16, кадры персонажа 32×32 и портреты 64×64. Полная настройка отображения по гайду входит в план серии 1.

Правила и размеры описаны в [docs/art.md](docs/art.md). Стиль утверждён 31 октября 2026 года; образцы находятся в `assets/art/style-test/`, актуальная городская графика — в `assets/art/style-test/city-v2/`.

Часть графики создана с помощью OpenAI image_gen и PixelLab, затем обработана в Aseprite. Происхождение, запросы и обработка записаны рядом с ассетами: [CREDITS.md](assets/art/style-test/CREDITS.md), [описание городских тайлов](assets/art/style-test/tiles_city_README.md), [городская графика v2](assets/art/style-test/city-v2/README.md).
