# План серий стримов

Серия стримов о том, как мы делаем Epiphany — игру о мифах про Ледовое побоище — на Godot 4.7. Сюжет, персонажи и реплики — в [story.md](story.md), правила графики и список ассетов — в [art.md](art.md).

## Как устроена серия

- Каждая серия — одна цель и играбельный результат в конце.
- Перед стримом заводим issue на серию. На стриме работаем в ветке от `dev`, в конце открываем PR в `dev`.
- После серии сливаем `dev` в `main`, ставим тег `ep-NN` и выкладываем web-сборку на itch.io.
- До серии 12 сборку загружаем на itch.io вручную (zip через сайт). В серии 12 настраиваем автоматическую выкладку.

Ход стрима (2–2,5 часа):

1. Что было в прошлый раз — играем в прошлую сборку.
2. Цель серии и план.
3. Основная работа.
4. Демо, сборка, выкладка, анонс следующей серии.

### Серия готова, когда

- [ ] `gdlint` без ошибок, код отформатирован `gdformat`.
- [ ] В выводе Godot и в консоли браузера нет ошибок.
- [ ] Новая сборка открывается на itch.io.
- [ ] PR смержен в `dev`, `dev` слит в `main`, стоит тег `ep-NN`.
- [ ] Все пункты «Что работает в сборке» проверены руками.

## Серия 1. Окружение и чистка

**Цель:** привести прототип в порядок и выложить первую сборку в браузере.

**Что делаем:**
- Коммитим то, что накопилось при подготовке: обновление проекта до Godot 4.7, файлы `.uid`, `.mcp.json`, `.claude/settings.json`.
- Показываем инструменты: Godot 4.7, VS Code с godot-tools, `gdformat` и `gdlint`, godot-mcp.
- Настройки проекта:
  - рендерер Compatibility — без него не будет веб-версии;
  - стартовая сцена `main_scene.tscn` вместо мини-игры со словами;
  - базовое разрешение 640×360 с целым масштабированием и привязкой к пикселям — по таблице из [art.md](art.md);
  - предупреждения о нетипизированном коде.
- Новая структура папок: `autoload/`, `ui/`, `locations/`, `minigames/`, `data/`, `assets/`. Файлы переносим в редакторе Godot, а не в терминале — тогда он сам обновит ссылки в сценах.
- Стиль кода: имена в snake_case, `letter-game.gd` → `letter_game.gd`, `gdformat` по всему проекту.
- Пресет экспорта Web (однопоточный), первая сборка, страница игры на itch.io.

**Что работает в сборке:**
- [ ] Игра открывается в браузере по ссылке на itch.io.
- [ ] Стартует вступление: картинка, текст, кнопка «Начнём!».
- [ ] По кнопке открывается город, персонаж ходит стрелками.
- [ ] Игра масштабируется под размер окна целым множителем, пиксели везде одного размера.

**Известные ограничения:** персонаж проходит сквозь здания, войти в здания нельзя. Мини-игра со словами из игры недоступна.

**Темы Godot:** настройки проекта, рендереры и веб, пресеты экспорта, стиль GDScript.

## Серия 2. Каркас игры

**Цель:** заменить ручное переключение сцен и колбэки общим каркасом, на котором держится вся игра.

**Что делаем:**
- `GameState` (autoload):
  - карточки К1–К5 (перевёрнута или нет), находки Н1–Н5, пройденные локации;
  - сигналы `card_flipped`, `finding_found`, `location_visited`;
  - метод `reset()` для новой игры.
- `SceneRouter` (autoload): `go_to(сцена)` с затемнением через CanvasLayer, ColorRect и Tween.
- Сигналы вместо полей-колбэков: вступление шлёт `finished`, окно с текстом — `closed`.
- Титульный экран: название, «Новая игра», «Выход» (в веб-версии «Выход» скрыт).
- Отладочная панель по F1 — только при запуске из редактора: состояние `GameState`, кнопки «перевернуть карточку» и «отметить локацию».
- По желанию: GUT и первые тесты для `GameState`.

**Что работает в сборке:**
- [ ] Игра начинается с титульного экрана.
- [ ] «Новая игра» → вступление → город, все переходы с затемнением.
- [ ] (в редакторе) F1 показывает состояние игры, изменения сразу видны на панели.

**Темы Godot:** autoload, сигналы, Tween, CanvasLayer, принцип «вызов вниз, сигнал вверх».

- Переносим пролог из [story.md](story.md) в `prologue.dialogue`: пять кадров, студент и Глеб.
- Закрываем дыру в пятом кадре: Глеб реагирует на «тупые немцы… провалились», но в сценарии студент говорит это только про себя. Пусть бормочет вслух, когда записывает тезисы.
- Портреты пока заглушки.

**Что работает в сборке:**
- [ ] После «Новой игры» идёт пролог из пяти кадров.
- [ ] Реплики студента и Глеба с именами и портретами, текст печатается по буквам.
- [ ] Клик или пробел сначала дописывает реплику, потом переходит к следующей.
- [ ] После «Начнём!» открывается город.

**Темы Godot:** аддоны и плагины, Dialogue Manager, RichTextLabel, обработка ввода.

## Серия 4. Блокнот и карточки

**Цель:** сквозная механика игры — блокнот с карточками-мифами и окно «прозрения».

**Что делаем:**
- Ресурсы данных: `CardData` (id, миф, факт, источник) — пять файлов `.tres` с текстами из сценария; `FindingData` — пять находок.
- Блокнот: открывается по Tab или кнопке в углу поверх любой сцены, показывает карточки и найденные находки.
- Переворот карточки: анимация через Tween (карточка сжимается по ширине, меняет сторону, раскрывается).
- Окно «Прозрение»: «Было / Стало / Источник». Его потом вызывают все локации.
- В прологе карточки появляются в блокноте по ходу третьего кадра — по команде из диалога.

**Что работает в сборке:**
- [ ] На третьем кадре пролога в блокноте одна за другой появляются пять карточек-мифов.
- [ ] В городе Tab открывает и закрывает блокнот.
- [ ] (в редакторе) Переворот карточки через F1 показывает анимацию и окно «Прозрение».

**Темы Godot:** Resource и свои классы данных, Tween, вёрстка в Control, InputMap.

## Серия 5. Город

**Цель:** город, по которому можно ходить и из которого можно попасть в локации.

**Что делаем:**
- Смотрим и вливаем ветку `walkable-v2`: в ней есть невлитый коммит «walkable map complete» (шрифт, доработки карты).
- Тайлсет перекрашиваем в палитру Resurrect 64, студента перерисовываем в кадр 32×32 вместо нынешнего 64×64 (см. [art.md](art.md)).
- Персонаж на CharacterBody2D, коллизии зданий через физический слой TileSet.
- Camera2D следует за персонажем и ограничена краями карты; карта больше экрана.
- Здания: музей, архив, кинотеатр, сквер и университет. В сценарии вход в финал не описан — предлагаю сделать его через университет.
- У каждого входа зона Area2D и подсказка «E — войти».
- Заглушки локаций: «Музей. Скоро здесь будет мини-игра» и кнопка «Назад». Вход в заглушку отмечает локацию пройденной.
- Сквер закрыт, пока не пройдены две локации; университет закрыт до сквера.
- Реплики студента из сценария: при выходе из дома и при повторном входе в локацию.

**Что работает в сборке:**
- [ ] Персонаж не проходит сквозь здания, камера едет за ним.
- [ ] У входа видна подсказка, по E открывается заглушка локации, «Назад» возвращает к тому же входу.
- [ ] После двух любых локаций открывается сквер, студент говорит реплику про памятник.
- [ ] Пройденные здания помечены на карте.

**Темы Godot:** CharacterBody2D и `move_and_slide`, физика в TileMapLayer, Camera2D, Area2D, сортировка по Y.

## Серия 6. Музей

**Цель:** первая полноценная локация и общий порядок работы мини-игр.

**Что делаем:**
- Общий контракт мини-игр: класс `Minigame` с методом `setup(data)` и сигналом `finished(result)`. Роутер запускает мини-игру, ждёт `finished` и отмечает результат в `GameState`.
- Интерьер музея, смотрительница Зинаида Петровна, диалоги до и после мини-игры.
- Мини-игра сравнения на основе готовой заготовки:
  - кликабельные зоны на обеих фигурах;
  - клик подсвечивает пару и открывает две таблички;
  - шкала «кто тяжелее» после каждой пары остаётся посередине;
  - пять пар: шлем, доспех, щит, копьё, плащ.
- В конце — «Прозрение» К2.

**Что работает в сборке:**
- [ ] В музее сначала разговор со смотрительницей, затем мини-игра.
- [ ] Клик по детали подсвечивает пару и показывает таблички, шкала остаётся посередине.
- [ ] После пяти пар — финальный диалог и окно «Прозрение», К2 в блокноте перевёрнута.
- [ ] При повторном входе — короткая реплика вместо мини-игры.

**Темы Godot:** наследование и `class_name`, `await` сигнала, кликабельные области в Control.

## Серия 7. Архив

**Цель:** переписать мини-игру со словами в поиск по летописи.

**Что делаем:**
- Сетка строится кодом из списка слов, а не из 36 клеток, расставленных вручную.
- Слова лежат по горизонтали и вертикали, пустые клетки заполняются случайными буквами.
- Выделение протягиванием в любую сторону. Клетку определяем по позиции мыши — в прототипе слово засчитывалось только слева направо.
- В списке семь слов. «УТОНУЛИ» найти нельзя: когда найдены остальные шесть, оно зачёркивается с пометкой «в летописи нет».
- Комментарии Лидии Марковны при каждой находке и большой диалог после.
- «Прозрения» К3 и К4, находки Н2 и Н3.

**Что работает в сборке:**
- [ ] Сетка 6×6 со словами СВИНЬЯ, УЗМЕНЬ, СЕЧА, ЧУДЬ, ЛЁД, ПОЛК.
- [ ] Слово засчитывается при протягивании в обе стороны, найденные слова подсвечены.
- [ ] После шести слов «УТОНУЛИ» зачёркивается и начинается диалог.
- [ ] К3 и К4 перевёрнуты, в блокноте появились Н2 и Н3.

**Темы Godot:** создание узлов из кода, GridContainer, `_gui_input` и координаты, Line2D.

## Серия 10. Финал

**Цель:** игру можно пройти от начала до конца.

**Что делаем:**
- Аудитория: Ирина Сергеевна, однокурсники, Глеб на последнем ряду.
- Титульный слайд: выбор даты. Третий вариант, с пересчётом на 12 апреля, доступен только с находкой Н5.
- Пять слайдов: на каждый кладём карточку и выбираем сторону. Неперевёрнутую карточку можно положить только мифом.
- Реакции преподавательницы на миф и на факт, бонусные слайды за находки Н1–Н4.
- Подсчёт и три концовки: «Прозрение», «Почти», «По фильму». Титр EPIPHANY.
- «Ещё раз» сбрасывает `GameState` и возвращает на титульный экран.

**Что работает в сборке:**
- [ ] Игру можно пройти от титульного экрана до концовки.
- [ ] Все три концовки достижимы — проверяем, выбирая мифы и факты.
- [ ] «Ещё раз» начинает новую игру с чистого состояния.

**Темы Godot:** сборка интерфейса из данных, сцена-«режиссёр», сброс состояния.

## Серия 12. Релиз

**Цель:** выпустить версию 1.0 и автоматизировать выкладку.

**Что делаем:**
- Ставим butler и привязываем его к аккаунту itch.io.
- GitHub Actions: по тегу `v*` Godot без окна собирает веб-версию, а butler выкладывает её на itch.io. Ключ itch.io храним в секретах репозитория.
- Страница игры: описание, скриншоты, обложка, управление.
- Плейтест со зрителями, правим найденные баги.
- Тег `v1.0`, ретроспектива всей серии.

**Что работает в сборке:**
- [ ] Тег `v1.0` автоматически публикует сборку на itch.io.
- [ ] Страница игры оформлена и открыта для всех.
- [ ] Игра проходится без ошибок в Chrome и Firefox. Safari проверяем отдельно: у него бывают проблемы с WebGL 2.

**Темы Godot:** экспорт из командной строки, CI на GitHub Actions, butler, публикация на itch.io.

## Зависимости и сокращённый вариант
