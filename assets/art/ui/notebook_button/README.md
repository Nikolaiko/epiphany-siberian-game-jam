# Кнопка блокнота в городе

Состояния кнопки «Блокнот · Tab» из макета, 20 ноября 2026 года.
PNG лежат уровнем выше, в `assets/art/ui/`, рядом с существующими кнопками.

Все игровые текстуры: **128×32 px**, Indexed PNG, Resurrect 64,
прозрачность только 0 или 255, без сглаживания. Отображение — Nearest.

| Файл | Состояние | Поле TextureButton |
|---|---|---|
| `ui_button_notebook_active.png` | Обычное, кнопка доступна | `texture_normal` |
| `ui_button_notebook_rollover.png` | Наведение: светлее подложка, тёплая верхняя кромка | `texture_hover` |
| `ui_button_notebook_pressed.png` | Нажатие: утопленная поверхность и сдвиг на 1 px вниз | `texture_pressed` |
| `ui_button_notebook_disabled.png` | Отключено: приглушённые серые цвета | `texture_disabled` |
| `ui_button_notebook_focus.png` | Прозрачная рамка клавиатурного фокуса | `texture_focused` |

`focus` — только рамка. Godot накладывает её поверх обычного состояния,
наведения или нажатия; отдельные комбинации не нужны. Она не скрывает
рисунок и надписи. На превью показана рамка поверх обычной кнопки.

## Надписи

По стайл-гайду текст рисует Godot, он не встроен в игровые PNG.
В текстурах есть пиксельный значок блокнота и пустая рамка клавиши.

- «Блокнот»: область `(31, 7, 61, 18)`, выравнивание по центру.
- «Tab»: область `(98, 9, 19, 12)`, выравнивание по центру.
- Цвет текста: `#4c3e24`, в отключённом состоянии — `#625565`.
- В нажатом состоянии обе надписи сдвигаются на **1 px вниз**.
- Для надписей установить `mouse_filter = IGNORE`, чтобы они не перехватывали клик.

Кнопка остаётся на экране города с отступом 12–16 px от правого и нижнего
края. Нажатие открывает блокнот; `Tab` служит подсказкой управления.
Набор содержит только графику, подключение к сцене не выполнялось.

## Исходник и превью

- `ui_button_notebook.aseprite` — пять кадров с тегами состояний.
- `ui_button_notebook_preview.png` — обзор с примером текста, **не для игры**.
- `ui_button_notebook_preview_3x.png` — тот же обзор, увеличенный ×3 без сглаживания.
- `generate.lua` — воспроизводимая отрисовка и проверка ассетов в Aseprite.

Воспроизведение из корня проекта (перезаписывает только файлы этого набора):

```sh
/Applications/Aseprite.app/Contents/MacOS/aseprite --batch \
  --script-param root="$PWD" \
  --script assets/art/ui/notebook_button/generate.lua
```

Оригинальный пиксельный значок нарисован специально для этого набора.
Форма, цвет бумаги, расположение значка и клавиши основаны на согласованном
макете кнопки в чате. Рисунок создан в Aseprite из геометрических примитивов,
без генерации нейросетью. Надписи на превью — вспомогательный bitmap-шрифт;
игровой шрифт задаётся в Godot.
