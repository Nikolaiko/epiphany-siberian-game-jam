# Графика блокнота

Набор от 21 ноября 2026 года. Продолжает стиль кнопки «Блокнот · Tab»:
тёмно-зелёный переплёт, тёплая бумага, коричневые чернила, контур в один
пиксель. Все 39 игровых PNG используют **Resurrect 64**, имеют целочисленные
края и прозрачность только 0/255. Фильтрация в Godot — **Nearest**.

**Игровые текстуры не содержат текста.** Подписи, номера карточек, счётчики,
мифы, факты и источники добавляются узлами `Label`/`RichTextLabel` в Godot.
Крестик, вопрос и галочка — графические значки, их текстом дублировать не нужно.

## Первый экран в Godot

В уже созданной сцене `ui/notebook_menu/notebook_menu.tscn` можно собрать:

```text
NotebookMenu (Control, Full Rect)
├── Dimmer (ColorRect, Full Rect)
└── Book (Control, 480×300, центр экрана)
    ├── Background (TextureRect: ui_notebook_open.png)
    ├── Title (Label)
    ├── Tabs
    ├── CloseButton (TextureButton)
    ├── Entries (VBoxContainer)
    ├── CardDetails (Control)
    └── Footer (Label)
```

При разрешении 640×360 позиция `Book` — **(80, 30)**. Размер 480×300.
Сам разворот показывать целиком, без растяжения и без 9-slice: иначе сместится
переплёт. Окно масштабируется вместе с игровым viewport целым множителем.

`Dimmer` — цвет `#2e222f` с непрозрачностью около 65%. Это `ColorRect`,
отдельная полупрозрачная картинка для него не нужна.

У всех декоративных `TextureRect` и надписей — `Mouse Filter = Ignore`;
кнопки получают мышь. Когда блокнот открыт, его логика должна блокировать
управление персонажем.

## Состояния элементов

| Суффикс | Использование |
|---|---|
| `normal` | Обычный фон |
| `hover` | Наведение |
| `pressed` | Нажатие кнопки; надпись также сдвигается на 1 px вниз |
| `selected` | Выбранная вкладка или строка списка |
| `disabled` | Отключённое действие |
| `focus` | Только рамка; прозрачная середина, рисовать поверх текущего состояния |

Кнопки действий и закрытия используют `normal`, `hover`, `pressed`, `disabled`,
`focus` в полях `TextureButton.texture_normal`, `texture_hover`,
`texture_pressed`, `texture_disabled`, `texture_focused` соответственно.

Для строк и вкладок: `normal`, `hover`, `selected`, `disabled`, `focus`.
При `toggle_mode = true` выбранный фон можно назначить в `texture_pressed`;
для взаимоисключающего выбора использовать группу кнопок.

На невыбранной строке, содержащей пока непроверенный миф, остаётся обычный
фон и вопрос. `disabled` не означает «факт пока неизвестен»: миф всё равно
можно читать. `unknown` предназначен для ещё не полученной карточки, а не
для всех непроверенных тезисов.

Переключение на факт доступно после открытия факта. Окно «Прозрение»
показывается при получении открытия; отдельной кнопки «Прозрение» на
постоянном развороте нет.

## Растягиваемые панели

У всех файлов с `nine_slice` в манифесте фиксированные края — **8 px** со
всех четырёх сторон. Это панели, строки, вкладки и длинные кнопки.
Для трёх основных панелей рядом с PNG есть готовые `StyleBoxTexture` `.tres`.
Назначай их в `PanelContainer → Theme Overrides → Styles → Panel`.

При использовании `NinePatchRect`: `Patch Margin Left/Top/Right/Bottom = 8`.
Не растягивать иконки, кнопку-крестик, обложку, разворот и карточки.
Для `TextureButton` используй PNG в исходном размере; он не применяет 9-slice.

Карточки 96×128: область заголовка `(8, 13, 74, 14)`, текста
`(8, 35, 78, 58)`, короткого источника `(8, 104, 78, 16)`.
Полные длинные факты и библиографические названия удобнее читать справа
на развороте. Небольшие карточки подходят для кратких тезисов и финального доклада.

## Исходники и превью

`source/` содержит редактируемые Aseprite-файлы с тегами состояний и скрипт
воспроизводимой отрисовки. Формы и иконки нарисованы в Aseprite на основе
согласованного макета и существующей кнопки; генерация нейросетью не использовалась.

`preview/notebook_layout.png` — пример сборки в **640×360**;
`preview/notebook_layout_2x.png` — его увеличение ×2.
`preview/notebook_asset_sheet.png` — обзор набора, также есть увеличение ×2.
Надписи в превью — демонстрационные. **Картинки из preview не назначать
как игровые текстуры.**

Перегенерация из корня проекта (перезаписывает только файлы этого набора):

```sh
/Applications/Aseprite.app/Contents/MacOS/aseprite --batch \
  --script-param root="$PWD" \
  --script assets/art/ui/notebook/source/generate.lua
```

После экспорта скрипт проверяет фактические размеры всех игровых PNG,
палитру, отсутствие полупрозрачных пикселей и прозрачную середину рамок фокуса.
Сцена блокнота и её логика в этот набор не входят.
