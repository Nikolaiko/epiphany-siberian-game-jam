# Городские тайлы — стайл-тест

Базовый набор по `docs/art.md`: 35 элементов на сетке 16×16, палитра Resurrect 64, свет сверху слева, без текста. Это набор для проверки стиля и ручной сборки улиц.

## Файлы

| Файл | Содержание |
|---|---|
| `tiles_city_terrain.png` | 64×64: 16 тайлов асфальта, тротуара, травы, земли, дорожной разметки, переходов и прямых бордюров |
| `tiles_city_buildings.png` | 64×64: 8 деталей 16×16 и 4 модуля 16×32 — крыши, карнизы, стены, окна и двери |
| `tiles_city_props.png` | 64×64: два дерева 32×32, скамейка 32×16, куст и урна 16×16, два фонаря 16×32; прозрачный фон |
| `tiles_city_atlas.png` | Общий атлас 192×64: покрытия, здания, декор слева направо |
| `tiles_city.tres` | Godot TileSet: 35 элементов с учётом размеров крупных объектов |
| `tiles_city_manifest.json` | Названия, группы, координаты и размеры элементов в клетках общего атласа |
| `tiles_city_street_preview.png` | Пример улицы 640×360, собранный из экспортированных тайлов |

Для листов и атласа сохранены редактируемые `.aseprite` и превью `_preview_4x.png`; для примера улицы — превью ×2. Исходные изображения генератора сохранены без изменений в `tiles_city_*_source.png`.

## Использование в Godot

Назначь `tiles_city.tres` свойству Tile Set нового TileMapLayer. Размер базовой клетки — 16×16, поля и промежутки — 0, идентификатор источника атласа — 0. Используй фильтр Nearest и целое увеличение. Крупные объекты уже объединены в тайлы нужного размера, их не требуется собирать из отдельных четвертей.

Сам ресурс TileSet содержит графическую нарезку без terrain/autotiling. В наборе есть прямые бордюры; угловые переходы для автоматического соединения дорог потребуют отдельного расширения набора.

## Примерный город в игре

`scenes/walkable_city/City.tscn` теперь использует новые тайлы. В `tile_map_layer.tscn` сохранена редактируемая карта 1280×768: дом студента, музей, архив, кинотеатр, университет, кофейня, сквер, два пересекающихся проезда и пешеходные дорожки.

Студент начинает у дома. Сохранены его спрайты и анимации; движение переведено на CharacterBody2D, камера следует за ним. У зданий, деревьев, скамеек, фонарей и границ карты настроены препятствия. Входы обозначены узлами Entrance; переходы в интерьеры пока не подключены.

Для просмотра открой `City.tscn` и запусти текущую сцену (F6). Управление — стрелками. Скриншоты из Godot: `city_playable_preview.png` и `city_overview.png`.

`build_city_scene.gd` воспроизводит первоначальную раскладку карты. Повторный запуск этого скрипта перезаписывает `tile_map_layer.tscn`, поэтому после ручных правок карты его запускать не нужно.

## Происхождение и обработка

Генерация: встроенный OpenAI image_gen, 31 октября 2026. Полные запросы:

- [Покрытия](tiles_city_terrain_prompt.txt)
- [Здания](tiles_city_buildings_prompt.txt)
- [Декор](tiles_city_props_prompt.txt)

Обработка в Aseprite: приведение к точным размерам методом nearest-neighbor, удаление тонких разделителей между покрытиями, размещение объектов внутри выделенных клеток, выбор ближайших цветов из тематических подмножеств Resurrect 64 без дизеринга, прозрачность только 0 или 255. Скрипт: `tiles_city_process.lua`. Художественная ручная ретушь не выполнялась.

Проверены размеры PNG, принадлежность цветов палитре, отсутствие полупрозрачных краёв и загрузка 35 элементов TileSet в Godot 4.7. Пример улицы предназначен для оценки повторяемости рисунка, плотности деталей и масштаба объектов.
