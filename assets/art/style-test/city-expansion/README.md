# Дополнение к городу — 8 зданий и 24 объекта

Готовый набор для ручной расстановки. Стиль продолжает принятую версию city-v2: мягкий осенний день, приглушённые материалы, палитра Resurrect 64. Существующая городская сцена не менялась.

## Файлы

- **buildings/** — 8 отдельных PNG и редактируемые файлы Aseprite.
- **props/** — 24 отдельных PNG и редактируемые файлы Aseprite.
- **atlases/buildings.png** — общий лист зданий, 1024×384.
- **atlases/props.png** — общий лист объектов, 768×288. Строки: улица, растения, двор.
- **city_expansion.tres** — необязательный готовый TileSet Godot; 32 цельных многоклеточных тайла, сетка 16×16. Source 0: здания, Source 1: декор.
- **atlas_manifest.json** — размеры, прямоугольники на листах и привязки отдельных PNG.
- **previews/overview.png**, **overview_2x.png** — обзор при исходном масштабе и увеличении ×2; это справочные листы, не фоны игры.
- **sources/** — все 11 первоначальных генераций без изменений и 2 пробных варианта очистки прозрачности.
- **prompts/** — полные запросы. **generation_manifest.json** — параметры генерации и список референсов.

## Как добавить вручную

Для TileMapLayer назначь city_expansion.tres в поле Tile Set либо перенеси нужные атласы в свой TileSet. Каждый объект уже выделен целиком: его можно ставить одним тайлом. У готовых тайлов основание совмещено с низом клетки, сортировка задана по основанию. Для перекрытия персонажа включи Y Sort у слоя и родителя.

Отдельный PNG можно использовать в Sprite2D в масштабе 1:1: при centered=true смещение offset=(0, -height/2) помещает точку привязки внизу по центру. Фильтр Nearest. Координаты и размеры всех объектов кратны 16; большинство объектов занимает несколько клеток.

Коллизии и интерактивность не добавлены. Это декоративные объекты; при необходимости настрой препятствия только у основания. Ограды — отдельные секции, не автотайлы для бесшовных поворотов.

## Происхождение и обработка

Дата: 31 октября 2026. Генерация встроенным OpenAI image_gen. Прямые референсы: ../city-v2/home.png, ../city-v2/cafe.png и ../char_student_atlas.png. Они продолжают утверждённый стиль кофейни. Палитра Resurrect 64 — Kerrie Lake, файл ../../../palette/resurrect-64.gpl.

После генерации каждый силуэт отдельно выделен по прозрачности и уменьшен в Aseprite с сохранением пропорций. В каждой исходной области выбран наиболее частый цвет тематического подмножества палитры. Прозрачность сведена к 0/255, края без сглаживания, без дизеринга. При покрытии меньше 40% итоговый пиксель прозрачен; порог исходной альфы 128. У архитектуры исключены зелёные оттенки, чтобы серые крыши не получали зелёные точки.

На двух исходных листах видимая RGB-подложка находится главным образом в прозрачных пикселях. Пробные варианты background_cleanup сохранены, но для итогового набора выбраны первоначальные более приглушённые цвета; прозрачные RGB-поля удалены при переводе в Indexed. Художественная ручная ретушь не выполнялась.

process.lua воспроизводит PNG, Aseprite, атласы и обзор. Регионы нарезки проверены по фактическим положениям объектов; предполагаемая генератором сетка не используется вслепую. sources, prompts и previews исключены из импорта Godot через .gdignore.

Проверки: 32 отдельных ассета и 2 атласа; размеры и области кратны 16; все видимые цвета входят в палитру; альфа только 0/255; области на листах не пересекаются. Ресурс TileSet содержит 8 зданий и 24 объекта.
