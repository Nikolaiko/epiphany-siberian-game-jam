# Город v2 — дневной свет, визуальный язык кофейни

Вторая попытка после отклонения первой версии по стилю и атмосфере. Город дневной: переносим из кофейни рисунок материалов, сливово-серые тени, тёплое дерево и кирпич, а не вечернее освещение. Прямые референсы генерации — `../bg_cafe_evening_source.png` и `../char_student_atlas.png`.

## Генерация и обработка

Встроенный OpenAI image_gen, 31 октября 2026. Полные запросы: [дом](home_prompt.txt), [музей](museum_prompt.txt), [архив](archive_prompt.txt), [кинотеатр](cinema_prompt.txt), [университет](university_prompt.txt), [кофейня](cafe_prompt.txt), [покрытия](terrain_prompt.txt), [декор](props_prompt.txt). Оригиналы сохранены без изменений как `*_source.png`.

`process.lua` обрабатывает изображения в Aseprite. Используются точные цвета из Resurrect 64 (Kerrie Lake), без дизеринга; прозрачность 0 или 255. Для зданий и декора выбирается наиболее частый цвет палитры в каждом уменьшаемом участке, без смешивания цветов; для покрытий используется nearest-neighbor. У архитектуры исключены зелёные оттенки, дававшие артефакты на серых крышах. Сохранены редактируемые `.aseprite` и превью ×2. Художественная ручная ретушь не выполнялась.

## Интеграция

`apply_city.gd` обновляет только графику в `scenes/walkable_city/tile_map_layer.tscn`: покрытие, шесть зданий и декор. Раскладка, препятствия, входы, камера и настройки студента сохраняются. Предыдущая карта сохранена как `city_v1.tscn.bak`; первый набор ассетов остаётся в родительской папке.

Базовые тайлы асфальта и травы сведены к одному цвету; детали оставлены в отдельных вариантах с лужами и листьями, чтобы не создавать регулярную рябь на больших участках. Проверены размеры и палитра 14 итоговых PNG, бинарная прозрачность, движение, столкновения и доступность всех шести входов. Игровые скриншоты: `playable_preview.png`, `overview.png`, `cafe_preview.png`.

Первоначальный `../build_city_scene.gd` создаёт версию v1, поэтому его повторный запуск вернёт старую графику. После него потребуется повторно применить `apply_city.gd`.
